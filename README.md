# Uday Crackers — Gen‑Z Refresh (feat/uday-crackers-website)

This branch revamps the entire website for a bold, modern, and highly interactive Gen‑Z experience.

## What’s New
- Vibrant gradient hero with parallax layers, spark particles, and countdown timer
- Sticky glassmorphic navbar with mobile drawer and active section highlighting
- Product cards with hover effects, crackle/whistle/spark sound buttons, and WhatsApp CTAs
- Family Packs and Reviews sliders with touch support
- Masonry Glow Gallery with lazy images and lightbox-ready markup
- Festive popup (once per session) and contact quick message feedback
- Fully responsive layouts using CSS Grid/Flex and clamp typography
- Performance: lazy loading, preloaded hero image, optimized WebP slots, minimal JS, GPU-friendly effects

## Files Updated
- index.html — complete structural redesign with comments on major upgrades
- style.css — new theme, components, responsive rules, and effects
- script.js — interactivity: nav, particles, countdown, sliders, sounds, popup, form feedback

## How to Run
Open index.html directly or host via GitHub Pages. Assets referenced under /assets; images should be added/optimized as WebP.
